# SFBuddyKit

A Swift package for SF Symbol browsing, searching, and AI-powered symbol suggestions.

## Features

- 🔍 **Symbol Browsing**: Browse and search SF Symbols with customizable grid layouts
- 🤖 **AI Search**: Get intelligent symbol suggestions using Claude AI
- 🎨 **Rendering Modes**: Support for hierarchical, palette, and multicolor rendering
- ⚡️ **Vegas Mode**: Animated symbol effects and visual fun
- 📋 **Symbol Actions**: Track symbol usage, copying, and exporting

## Requirements

- macOS 14.0+ / iOS 17.0+
- Swift 5.9+
