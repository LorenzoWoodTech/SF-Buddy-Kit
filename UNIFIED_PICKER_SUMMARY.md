# Unified Symbol Picker

## Overview
Combined `SFSymbolBrowserView` and `SymbolPickerView` into one powerful unified view.

## Features

### 1. **Instant Local Filtering**
- Type to filter symbols in real-time from the entire SF Symbols library
- No AI query needed for basic searching
- Fast, responsive, immediate results

### 2. **AI-Powered Search on Enter**
- Press Enter to trigger Claude AI suggestions
- AI results shown in dedicated "AI Suggestions" section at top
- Purple accent color distinguishes AI suggestions from regular symbols
- AI suggestions stay visible while browsing other symbols

### 3. **Category Filtering**
- Toggle category bar with filter button
- 25 categories: Communication, Weather, Devices, etc.
- Works alongside search and AI suggestions
- Smooth animations when switching categories
